Place your project logo image here and name it `logo.png` or `logo.svg`.

The app loads `frontend/src/assets/logo/logo.svg` by default. Replace that file with your preferred logo image (keeping the same filename), or update the import path in `frontend/src/components/Header.js` to point to your image file.

Recommended sizes:
- `logo.svg`: scalable (preferred)
- `logo.png`: 128x128 or 256x256 for clarity

If you replace with a raster image, keep the filename `logo.png` and adjust the import in `Header.js` if needed.
